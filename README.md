# ميدان · Maydan

تطبيق جوال عربي (RTL) لمتابعة السلامة الميدانية: الشفتات، الزيارات، حضور الاجتماعات، والتقارير.
مبني بـ **Expo SDK 58 / React Native** و TypeScript، والأولوية للآيفون (يعمل كذلك على أندرويد والويب).

الكود في مجلد [`app/`](app). نموذج HTML الأصلي كان المرجع للشكل والسلوك.

## التشغيل

المتطلبات: Node.js 20 أو أحدث، وتطبيق **Expo Go** على الآيفون (من App Store).

```bash
cd app
npm install
npx expo start          # امسح رمز QR بكاميرا الآيفون ليفتح في Expo Go
```

- **محاكي iOS (على ماك مع Xcode):** `npx expo run:ios`
- **نسخة تثبيت للآيفون عبر السحابة (بدون Xcode):** `npx eas-cli@latest build -p ios --profile preview`
  (تحتاج حساب Expo وحساب Apple Developer).
- **معاينة على المتصفح:** `npx expo start --web`

> اتجاه الواجهة من اليمين لليسار مفعّل عبر `expo-localization` (`forcesRTL`). في Expo Go قد يحتاج التطبيق
> إعادة فتح مرة واحدة بعد أول تشغيل حتى يطبق الاتجاه.

## الاختبارات

```bash

# اختبار الواجهة على نسخة الويب بمقاس آيفون (Playwright)
npx expo export -p web

```

اختبار الواجهة (`app/e2e/flows.js`) يثبت الساعة على الإثنين 9 نوفمبر 2026 الساعة 10:00 بتوقيت السعودية ويتحقق من:
تسجيل زيارتين لنفس القسم في نفس اليوم وتعديل إحداهما بشكل مستقل، حفظ حضور اجتماعين دفعة واحدة،
نقل فني من «طوارئ أ» إلى «طوارئ ب»، زيادة أرقام التقرير بالقيم الصحيحة، البحث بالرقم الوظيفي، بقاء البيانات بعد إعادة التشغيل،
وانفصال وضع العمل عن وضع التجربة.

## ما في التطبيق

| الشاشة | الوظائف |
| --- | --- |
| **اليوم** | بطاقة الإنجاز (المستوى و XP)، تحدي 3 زيارات يوميًا، جدول أعمال اليوم من الخطة الأسبوعية (±7 أيام)، الشفت الحالي لكل قسم بتوقيت السعودية مع الفنيين وشفتهم الأساسي وزر «نقل/تكليف»، تقدمك في تغطية جميع الفنيين، وقائمة أولوية المتابعة. |
| **الزيارات** | اختيار القسم، فنيو الشفت الحالي أو كل القسم بألوان (صفر أحمر، 1 أصفر، 2+ أخضر)، إضافة أكثر من زيارة في اليوم مع الموقع/الوصف والفنيين، وسجل مستقل لكل زيارة قابل للتعديل والحذف. |
| **الاجتماعات** | إضافة عنوان اجتماع من نفس الصفحة، اختيار أكثر من اجتماع، جدول مربعات اختيار (فني × اجتماع) مع «الكل» لكل عمود، وحفظ دفعة واحدة. |
| **التقارير** | شهري / ربع سنوي / سنوي مع فلتر القسم، عدد الزيارات والاجتماعات ومرات الحضور، رسم عبر الفترة، التوزيع حسب القسم، المتبقي لكل قسم وشفت، من باقي عليه، تصدير CSV و PDF، والبحث بالرقم الوظيفي (يقبل الأرقام العربية). |
| **الشفتات** | جدول أي تاريخ: تبديل شفت اليوم أو تكليف فنيين ليوم واحد واستعادة الدورة، وعرض الفنيين حسب الشفت الأساسي مع النقل. |
| **الإعدادات** (⚙️ في الأعلى) | التبديل بين **وضع التجربة** و**بيانات العمل**، الأهداف، الأقسام والشفتات وأوقات الدوام وبداية الدورة ونمطها، الفنيون، عناوين الاجتماعات، الخطة الأسبوعية، ونسخة احتياطية JSON. |

## قواعد الحساب

- **التوقيت:** السعودية UTC+3 ثابت (بدون توقيت صيفي). الشفت المسائي بعد منتصف الليل يتبع تاريخ اليوم السابق.
- **دورة الشفتات:** نمط أيام يتكرر من «بداية الدورة»، وكل شفت يتأخر عددًا محددًا من الأيام عن السابق.
  مثال الطوارئ: صباحي، صباحي، مسائي، مسائي، 4 راحة، والتأخر يومان. أو دوام أسبوعي بأيام ثابتة.
- **الشفت الأساسي** يحدد دوام الفني في الدورة (النقل دائم). **تكليف اليوم** يخص تاريخًا وفترة فقط.
- **هدف الزيارات:** زيارتان لكل فني خلال آخر 6 أشهر (قابل للتعديل).
- **هدف الاجتماعات:** حضور كل اجتماعات السنة المضافة.
- **الزيارة الجماعية:** زيارة شملت 3 فنيين = **زيارة واحدة** في التقرير، و**زيارة لكل فني** في سجله.
  التقرير يعرض الرقمين معًا: «زيارات» و«زيارات الفنيين».
- **تسجيل الاجتماع** = سجل (اجتماع × قسم × تاريخ). «مرات الحضور» مجموع الحاضرين في هذه السجلات.
- **المتبقي في التقرير** يُحسب حتى نهاية الفترة المختارة، أو حتى اليوم إذا كانت الفترة الحالية.
- **XP:** الزيارة 30، وتسجيل حضور الاجتماع 20، وكل 100 XP مستوى. سجلات التجربة الأولية لا تُحتسب في نقاطك.

## البيانات

- **وضع التجربة:** أسماء وأرقام وظيفية وأوقات دوام تجريبية (من النموذج)، مع زيارات وحضور سابقين للعرض.
  يمكن إعادته لحالته الأصلية من الإعدادات.
- **بيانات العمل:** تبدأ بهيكل الأقسام الخمسة (عدادات، طوارئ، مساح، صيانة، الإنشاءات) بدون فنيين.
  تضيف الفنيين وتعدل الشفتات والأوقات من الإعدادات. الوضعان منفصلان تمامًا.
- كل البيانات محفوظة على الجهاز (AsyncStorage). صدّر نسخة احتياطية من الإعدادات بشكل دوري.

## هيكل الكود

```
app/
  App.tsx                    الهيكل: الرأس، التبويبات، النوافذ المنبثقة
  src/domain/                منطق العمل بدون واجهة (مغطى بالاختبارات)
    dates.ts                 توقيت السعودية والتواريخ العربية
    shifts.ts                الدورات، الشفت الحالي، النقل والتكليف اليومي
    records.ts               الزيارات، الاجتماعات، حفظ الحضور دفعة واحدة
    stats.ts                 تقدم الفني، المتبقي لكل قسم وشفت، أولوية المتابعة، XP
    reports.ts               التقارير الدورية، CSV، و HTML لملف PDF
    plan.ts                  الخطة الأسبوعية وإعداد بيانات العمل
    seed.ts                  بيانات وضع التجربة والهيكل الافتراضي
  src/screens/               الشاشات
  src/sheets/                النوافذ: الزيارة، الشفتات، الإعدادات
  src/store.tsx              الحالة والحفظ على الجهاز
  src/exporting.ts           المشاركة (CSV/PDF) عبر expo-print و expo-sharing
  e2e/flows.js               اختبار الواجهة
```
